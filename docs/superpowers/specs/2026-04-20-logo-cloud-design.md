## 1. 目标与范围

- 首页 **Logo 云 / Trusted by** 区块在视觉上与 Figma **`1-12194`** 对齐。
- 采用 **方案一（最小改动）**：在现有 `LogoCloud` 组件内用静态数组 + `next/image`；资源为仓库内静态文件，**不接 CMS**、不做配置化抽象（除非后续单独立项）。

**不在本规格范围：** 无限滚动动画、从接口拉取 logo 列表、多语言不同 logo 集（若需要另开规格）。

## 2. 源文件与实现落点

| 类型     | 路径                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 组件     | `src/app/homepage/components/LogoCloud.tsx`                             |
| 页面引用 | `src/app/page.tsx`（已引用则保持）                                      |
| 静态资源 | `public/mainpage/partners/`（URL 仍为 `/mainpage/partners/<filename>`） |

**说明：** Next.js 以项目根目录 `public/` 为静态资源根。实现阶段新增或替换的导出文件均放入 `public/mainpage/partners/`，与现有 `Partners` 等页复用路径约定一致。`locales/en/public/` 下若有同源副本，仅在项目存在明确同步脚本时跟随更新；**默认以 `public/mainpage/partners/` 为单一事实来源**。

---

## 3. 资源导出（Figma → 仓库）

1. 在 Figma **`1-12194`** Dev 模式下，按 **每个 logo 独立导出**（勿整张 raster 成一张大图），以保证视网膜屏与可维护性。
2. **格式优先级：** 矢量优先 **SVG**；仅当源稿为复杂栅格或 SVG 体积异常时，使用 **PNG @2x**，文件名仍用 kebab-case。
3. **命名：** 小写 + kebab-case，与组件内 `src` 一致（例如 `genspark.png`、`openrouter.svg`）。新增品牌时文件名与 `LogoItem.name` 在规格或 PR 描述中可一眼对应。
4. **色彩：** 若设计为浅底上的深色单色 logo，导出保持与设计一致；组件侧继续使用 **灰度 + 透明度 + hover** 时，应避免导出已是极浅灰导致滤镜后对比度过低。必要时在 Figma 中统一为单色系再导出。
5. **法律与品牌：** 使用官方提供的品牌资源规范；导出尺寸以设计稿约束高度为主，宽度 `object-contain`。

**实现前核对：** 当前仓库中 `public/mainpage/partners/` 已有部分文件；`LogoCloud` 若引用尚不存在的文件，必须在同一变更中补齐导出，避免构建或运行期 404。

---

## 4. 前端行为与样式（对齐方案一）

- **结构：** 区块标题（英文标签）+ 一行或多行 logo；布局保持 **flex + wrap + 居中**，除非 `1-12194` 明确要求固定列数或不同断点规则（以 Figma 为准微调 `gap` / `padding` / `max-width`）。
- **图片：** `next/image`，为每个条目保留 **显式 `width` / `height`**（或与 SVG 固有比例一致），`alt` 为品牌可读名称。
- **样式 token：** 背景、标题色、字级继续使用项目既有 CSS 变量与工具类（如 `var(--bg-light)`、`var(--text-2)`、`font-mono-13`）；若 Dev 模式标注与现实现偏差 **> 2px 或明显色值不一致**，以 Figma 为准改类名/变量映射，并在 PR 中注明对应 token。
- **注释：** 更新 `LogoCloud.tsx` 顶部 Figma 注释为 **`1-12194`**，避免与旧节点混用。

---

## 5. 验收标准

1. 在桌面与移动宽度下，**logo 集合、顺序、行数** 与 **`1-12194`** 一致（若设计为两行则两行；若设计调整数量则更新数组而非硬凑旧数量）。
2. 所有 `Image` 的 `src` 在运行时可访问，**无 404**。
3. 标题文案与 Figma **一致**（含大小写与标点）；若全局 copy 有统一文案表，以设计稿为准同步文案源。
4. 无障碍：`alt` 文本有意义；装饰性重复可由设计确认是否保留单一语义或 `alt=""`（默认每个品牌保留可读 `alt`）。
