# DateRangePicker

**源码**：`standard/date-range-picker.tsx`、`date-range-picker.module.scss`。

| 状态            | 区间 SCSS                                         | 单日（对照）                          |
| --------------- | ------------------------------------------------- | ------------------------------------- |
| **Hover**       | 仅 `background-color: var(--white)`（无边框色变） | `border-color: var(--brand-0)` + 白底 |
| **打开 / 已填** | `border-color: var(--dark-1)`                     | `border-color: var(--brand-0)`        |
| **警示**        | `border-color: var(--red-1)`                      | 同左                                  |
| **Footer**      | `border-top: var(--border-3)` + brand 链接        | 同思路                                |
