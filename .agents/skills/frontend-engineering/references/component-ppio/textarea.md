# Textarea

**源码**：`textarea.tsx`。

| 维度              | 规范                                                                       |
| ----------------- | -------------------------------------------------------------------------- |
| **圆角**          | `rounded-md`。                                                             |
| **默认**          | 边框 `border`（即 `border-border` / `--border-3`）；背景 `bg-background`。 |
| **Hover / Focus** | `hover:border-input-hover`、`focus:border-input-hover`；背景不变。         |
| **禁用**          | `disabled:opacity-50`。                                                    |
