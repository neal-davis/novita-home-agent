# ModelTag

**源码**：`model-tag/ModelTag.tsx`。

| 维度                 | 规范                                                                      |
| -------------------- | ------------------------------------------------------------------------- |
| **基础**             | `rounded-small`、`h-5`、`px-[6px]`。                                      |
| **动态色**           | `bg-[${bgColor}]` 等可能无法被 Tailwind 扫描；优先 `style` 或固定 token。 |
| **Double11ModelTag** | 渐变营销特例，不作控制台默认。                                            |
